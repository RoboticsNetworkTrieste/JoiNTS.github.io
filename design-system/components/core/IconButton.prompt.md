Icon-only button. Always pass `label` — it becomes both the aria-label and the tooltip.

```jsx
<IconButton icon="github" label="GitHub" variant="outline" href="https://github.com/joints" />
<IconButton icon="x" label="Chiudi" />
```

Use `outline` in headers and card corners, `solid` only for a single affirmative action. Minimum touch size is 44px on mobile — use `size="lg"`.

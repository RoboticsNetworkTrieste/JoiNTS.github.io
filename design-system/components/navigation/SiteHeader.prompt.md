The header for every joints.community page. Sticky, 72px, blurred `--surface-header` scrim over a hairline.

```jsx
<SiteHeader
  active="/progetti"
  links={[{label:'Manifesto',href:'/manifesto'},{label:'Progetti',href:'/progetti'},{label:'Eventi',href:'/eventi'}]}
  github="https://github.com/joints-trieste"
  cta={{ label: 'Entra', href: '/entra' }}
/>
```

Nav labels are single Italian words. Max 5 links.
